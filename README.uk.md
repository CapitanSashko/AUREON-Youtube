# AUREON YouTube

[🇺🇦 Українська](#українська) | [🇬🇧 English](#english)

**AUREON YouTube** — настільний застосунок для Windows, створений на C# із використанням Windows Forms та Microsoft Edge WebView2. Він забезпечує зручний доступ до YouTube, відтворення відео, режим мініпрогравача, голосовий пошук, а також завантаження відео, плейлистів і аудіо у форматі MP3.

## ✨ Можливості

- **YouTube у вбудованому вікні** — перегляд відео безпосередньо в застосунку.
- **Мініпрогравач (Picture-in-Picture)** — компактне плаваюче вікно для перегляду відео поверх інших програм.
- **Повноекранний режим** — підтримка повноекранного відтворення.
- **Голосовий пошук** — пошук відео за допомогою мікрофона.
- **Завантаження відео** — вибір якості: 1080p, 720p, 480p, 360p або найкраща доступна якість.
- **Завантаження плейлистів** — можливість завантажувати цілі плейлисти.
- **Вилучення аудіо** — збереження аудіодоріжок у форматі MP3.
- **FFmpeg** — об'єднання окремих відео- й аудіопотоків, додавання обкладинок і метаданих.
- **SponsorBlock** — можливість пропускати підтримувані рекламні та спонсорські сегменти.
- **Керування завантаженнями** — відображення прогресу, скасування завантаження та відкриття папки з файлами.
- **Системний трей** — системні сповіщення про стан завантажень.
- **Збереження налаштувань** — запам'ятовування розміру й положення вікна, останньої сторінки, параметрів мініпрогравача та налаштувань завантаження.
- **Оновлення yt-dlp** — перевірка актуальної версії через GitHub API.

## ⌨️ Гарячі клавіші

| Комбінація | Дія |
|---|---|
| `Ctrl + L` | Пошук |
| `F5` / `Ctrl + R` | Оновити сторінку |
| `Alt + ←` | Назад |
| `Alt + →` | Вперед |
| `Alt + Home` | Головна сторінка YouTube |
| `Ctrl + P` | Увімкнути мініпрогравач |
| `Esc` | Вийти з мініпрогравача |
| `Ctrl + D` | Завантажити відео |
| `Ctrl + Shift + D` | Завантажити плейлист |
| `Ctrl + Shift + O` | Відкрити папку завантажень |
| `Ctrl + Shift + C` | Скасувати завантаження |

## 🛠️ Технології

- C#
- .NET / Windows Forms
- Microsoft Edge WebView2
- yt-dlp
- FFmpeg
- JSON для збереження налаштувань

## 📋 Системні вимоги

- Windows 10 або Windows 11.
- Встановлений Microsoft Edge WebView2 Runtime.
- yt-dlp для завантаження відео та аудіо.
- FFmpeg — рекомендований для об'єднання потоків і додаткової обробки медіафайлів.

## ⚙️ Налаштування

Застосунок зберігає налаштування у форматі JSON. Серед них:

- Розмір і положення головного вікна.
- Остання відкрита сторінка.
- Положення та розмір мініпрогравача.
- Шлях для збереження завантажень.
- Обрана якість відео.
- Налаштування SponsorBlock.
